# 大肥鱼心智内核

把"记忆"从一堆文本变成**有寿命的数据**，并作为唯一的心智装配入口。

## 它做什么

1. 从旧库只读导入种子（`memory.db` / `brain.db` **不写一个字**）
2. 给每条记忆：权重 `w` / 锚定时间 / 回想次数 / 记忆池
3. 后台 tick：分段衰减 → 海马晋升 → 下沉归档
4. 向量召回：`bge-m3` 余弦 × 权重 × `f_endo`，按 token 预算截断
5. 技能记忆 SM2：熟练度 `L` / 易度 `EF` / 间隔 `I`，用得好越来越熟
6. 离线补偿：关机几天回来按压缩时间批量结算
7. 生命卡：把上面全部打包成一个文件

## 装配入口

`mind_get_context()` 一次拼好 **人格 + 心境 + 记忆 + 技能**，
`on_llm_request` 只注入一次。配合另外两个插件时设 `inject_mode=primary`。

## 命令

| 命令 | 作用 |
|---|---|
| `/心智` | 各池数量与平均权重 |
| `/心智状态` | 记忆 + 激素 + 人格 + 技能 一次看完 |
| `/心智找 关键词` | 具体记忆 + `×回想次数` |
| `/心智向量` | 补齐缺失向量 |
| `/心智调参` | 按当前数据建议晋升阈值 |
| `/心智衰减` | 手动结算一次 |
| `/技能` `/技能增` `/技能用` `/技能记录` `/技能衰减` | 技能管理 |
| `/离线补偿 10` | 模拟离线结算 |
| `/生命卡 导出` `/生命卡 导入` `/生命卡 列表` | 整包搬迁 |

## 配置要点

| 键 | 默认 | 说明 |
|---|---|---|
| `inject_mode` | primary | `off` / `supplement` / `primary` |
| `promote_mid` | 0.35 | 晋升中期阈值 |
| `promote_long` | 0.60 | 晋升长期阈值 |
| `embedding_api_base` | http://172.17.0.1:11434/v1 | Ollama |
| `embedding_model` | bge-m3 | |
| `token_budget` | 6000 | 上下文预算 |
| `memory_ratio` | 0.12 | 记忆占比 |
